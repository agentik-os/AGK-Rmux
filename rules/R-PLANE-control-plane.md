# R-PLANE — OmegaOS is the control plane — Hermes is the brain

**Kind:** Rule
**Category:** Orchestration
**Added:** 2026-08-26

## Rule

OmegaOS is the control plane (navigation, context, visualization); Hermes is the official AI brain; RMUX is persistent execution; Agentik Core is structured state. Never duplicate Hermes sessions, scrape ~/.hermes JSON, or become a session backend. Ask Hermes via `hermes -p <scope>` or `hermes gateway`. Official Hermes only so `hermes update` stays valid. OS packages live in ~/.omega/os (optional OMEGA_OS_ROOT); do not inject random OS files into Hermes.

## Origin

Operators treated OmegaOS as a second Hermes. Control plane vs brain must be doctrine.
