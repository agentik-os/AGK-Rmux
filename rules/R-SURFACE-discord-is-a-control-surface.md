# R-SURFACE — Discord is a control surface — bot ≠ agent

**Kind:** Rule
**Category:** Orchestration
**Added:** 2026-08-26

## Rule

Exactly four Discord bots (@Operator @Agentik @Mission @Private), plus optional Dev twins. A bot is a profile entrypoint, never an agent, client, or worker. Buttons / slash / natural language / Desktop / Web invoke the same canonical action. Discord is not source of truth; component IDs carry no secrets; do not spam raw logs.

## Origin

One-bot-per-agent and slash-only UX would fork the product into a terminal inside Discord.
