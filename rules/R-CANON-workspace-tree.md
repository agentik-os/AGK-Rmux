# R-CANON — Canonical AGK workspace tree

**Kind:** Rule
**Category:** Universal
**Added:** 2026-08-26

## Rule

Put work in the canonical `$HOME/workspace/<scope>/` tree (operator ops, agentik org, mission clients, private self) and never mix client work into private or operator into mission. Operator: infrastructure, security, deployments, monitoring, automation, deposit, docs. Agentik: projects, products, missions, research, content, growth, community, knowledge, artifacts. Mission: clients/<name>/{.client,projects,missions,knowledge,artifacts,infrastructure,automation,docs}, internal, shared. Private: projects, journal, goals, learning, research, knowledge, artifacts.

## Origin

Fresh installs left a flat home; client and private trees collided.
