# R-LAYER — Do not collapse session, project, mission, run

**Kind:** Rule
**Category:** Universal
**Added:** 2026-08-26

## Rule

Hermes session is AI context; RMUX session is a process; project is a body of work; mission is an objective; task is a unit; run is one execution; agent is an actor; OS is a methodology — never collapse these. One project may have many Hermes sessions and many RMUX runtimes. OmegaOS links ids; Hermes reasons; RMUX persists the process.

## Origin

Agents treated a dead rmux pane as a lost project and a Hermes chat as the mission ledger.
