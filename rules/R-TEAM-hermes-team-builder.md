# R-TEAM — Hermes orchestrates specialists via Team Builder

**Kind:** Rule
**Category:** Orchestration
**Added:** 2026-08-26

## Rule

Hermes is the master orchestrator: Mission Planner → OS Resolver → Team Builder → specialists (definition ≠ sub-agent ≠ run ≠ ephemeral worker). An OS composes a team (Research OS → planner/researchers/critic/synthesizer). Agents stay behind Hermes; they are not Discord bots. Parallel workers run on RMUX.

## Origin

Without Team Builder, every OS only injected docs and Hermes could not spawn parallel specialists.
